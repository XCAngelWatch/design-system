来源：用户在当前任务提供 `/Volumes/DavidData/temp/code/design-system 2/`，要求将最新 UI 修改的规范合入当前仓库。该副本基于旧提交 `779b939`；与上一份已审核副本按文件内容比较，只有 26 个文件存在新增差异。以主仓 `e5fd74b` 为基线逐项迁入，不覆盖既有国际化、无障碍、响应式、消费者契约及业务权威边界。

## 生效规则

- 二三级详情页、表单与沉浸式流程提供左箭头加文字的返回按钮。详情页可同时保留面包屑说明位置；表单与沉浸式流程不重复放置面包屑。顶级列表与仪表盘不显示返回。这替代旧的“普通详情页只显示面包屑”要求。
- 显式目标优先，其次使用已验证的站内访问来源；直接打开、刷新或来源不可用时回到稳定的业务父页。返回继续保留列表筛选、分页等状态和未保存表单拦截，不通过无条件 `history.back()` 退出应用。显式“返回首页/列表”使用对应固定目标。
- 应用 Shell 仅将面包屑放到顶栏；返回、标题、操作和其他页头内容仍留在内容区。紧凑页头保留返回入口，不恢复自由文本副标题槽。
- 文档站工具栏的返回用于文档章节访问历史，除概览外显示；它与业务蓝图的页面层级规则不同。演示中的父路由是站内示例导航，不构成业务流程契约。
- 表格达到 3 个动作时最多外露 2 个普通文字动作，其余进入带语义图标和文字的菜单。现有 `primary / secondary / menu` 用途、窄容器按宽度收纳、单一安全动作直接展示、危险动作最后及一次确认继续有效。禁用状态、处理中状态、键盘焦点和取消默认焦点不变；不机械把危险动作提到前两位。

新增返回控件覆盖详情、表单、向导、推送、结果、错误和 PageHeader 示例；向导的返回与底部“上一步”职责不同。共用样式使用当前主题 token 和可见的键盘焦点轮廓。同步中英文、工具栏窄屏布局以及行操作、表格、技术栈说明。

不迁入副本中早已被主仓修复的数值右对齐规则、自由文本副标题、虚构 `packages/web` 路径、浅色焦点阴影或按文字猜测危险操作的旧执行逻辑。文件模式、AppleDouble、OpenDesign 元数据、独立预览壳与参考图不属于运行时增量。
