## 决策

- AWTable 以现有 AntD v6 Table 能力为基础，集中管理布局、行操作、分页、状态与选择；通过可选查询控制器、请求 Hook 和表格区域容器组合完整列表。可选 `columnSettings: { schemaVersion, scopeKey }` 仅启用列显隐，`AWColumn.hideable` 声明可隐藏性；拖拽列顺序、手动调宽继续延后。
- 显示列入口位于结果工具栏右侧，与视图切换同组；不在表头放图标，不随固定列或横向滚动迁移。首个 identity（没有时首个业务列）和操作列仍始终必选，其他 identity 默认必选。草稿经应用才生效，取消/Escape/外点丢弃，恢复默认先将草稿改为全列。显隐不改变查询、页码、排序或选择。
- 列偏好只保存 schemaVersion 和 hiddenIds，以应用、用户/租户、表格 id、版本隔离；机构变化只关闭旧草稿，不清同身份偏好。新增列可见、未知和必选隐藏 id 清理、坏缓存安全降级，不读取旧 OTA 缓存。筛选面板沿用现有 token 的 16px 留白，分页左总数右控件、窄区换行，表格/卡片一致，不新增全局 token。
- AWTableFilters 基于资源包交互，采用“基础字段、高级字段、底部分隔线、左已启用计数 / 右展开、重置、搜索”结构；不显示独立标题行，保留区域可访问名称，提供 schema、受控 draft/applied、验证、展开和重置接口，可独立使用。
- 默认显式搜索；编辑和更多筛选展开只改变草稿/呈现。计数只按 applied 字段统计，合法 0/false 不当空，完整日期段计 1。收起保留全部字段，并从完整受控草稿提交，避免复制现有高级字段卸载后只读注册字段的缺陷。
- 每次通过完整草稿验证并被受理的搜索恰好调度一次读取：条件改变则完整更新 filters 并回第 1 页，相同条件保持当前页重新加载。pending 时防重复，完成或失败后可再次搜索；校验失败不刷新旧条件。
- 对应目标接口为 `table.search(values)`。query 状态可因相同值保持 identity，但搜索意图不能被 no-op 吞掉；变条件更新 query 与同条件推进内部 refreshVersion 是互斥路径，不允许一次搜索同时触发两个请求。内部 refresh/retry 可供重试或业务成功后重取，不渲染独立刷新按钮。
- 默认重置为过滤默认值并收起；排序和页大小由父查询控制器声明。资源包参照配置恢复 initialQuery 的排序/页大小与 page=1，保留机构/contextKey。搜索/重置为纯文字，不复制现有搜索图标；日期传输和时区仍由领域适配器负责。
- 受控数据是基础接口；已有请求框架不被强制替换。可选请求 Hook 只处理生命周期、取消与过期结果，具体 API、字段、状态、权限和业务效果由调用方提供。
- 每行最多 3 个可见入口，包含“更多”。无菜单时普通动作 1–3 项直接显示；4 项起或存在危险菜单项时最多保留前 2 项，其余进入“更多”。空间不足可继续收纳，登记的危险直接展示例外也不得突破 3 个入口，普通动作不能以“仅菜单”配置绕过计数规则。只有危险动作时允许只有“更多”。
- 表格行内、更多菜单、表格工具栏及批量条业务按钮使用纯文字；保留下拉、排序、选择、展开、加载和状态等必要交互标识，不改变全站返回或导航规则。
- 列宽按语义、当前语言和实际内容预算计算。单元格左右各 16px；整表操作列根据声明的有效动作组合取稳定宽度。主操作＋更多仍放不下时扩宽、解除必要固定并局部横滚，不截断或缩小按钮文案。
- 固定列必须保留关键非固定数据列的最小阅读区；实际容器不足时先解除次要左固定、再操作固定、最后身份列固定。文档示例里的 64px 不提升为通用规范。
- 查询状态只有一个有效变更出口，显式搜索只有一个意图入口；不能分别转发 AntD 表格和分页回调产生重复查询。分页、排序、搜索重新加载、末页校正和恢复有明确事件边界。
- 选择明确区分当前页、同查询跨页、已批准的同业务上下文和后端支持的全部匹配结果；contextKey 改变时按契约清理，避免旧上下文操作。
- 空数据、无匹配、首次加载、刷新、首次失败与刷新失败分别表达；旧响应的成功、失败和结束事件都不得覆盖新查询。
- 不引入第二套表格内核，不按固定条数自动切换内核，不以自动转换卡片代替窄屏表格支持。
- 复用当前 AppTable、分页纯函数、RowActions 执行锁/确认、容器测量、全文访问、状态原语和请求代际隔离；不复制旧两项折叠、菜单图标、固定动作列宽和双分页事件出口。17 类取舍与精确源码位置见复用审查。
- 将交互按事件落为状态、读取次数、选择与焦点/滚动规则。补充请求 ready/waiting/blocked 准入、共享同步协调器、异步验证快照、各区域独立失败、原上下文写后重取、批量确认快照/未知结果、严格恢复白名单及表单 untouched 字段保护。
- 机构树、表单壳、格式化/状态单元格、全文展示、导出和自动更新是配套组合能力；业务自动更新显式启用，普通表格不默认轮询。本次列显隐批准不扩展为列拖拽或调宽能力。
- 设计页先展示交互预览，再按需展开源码依据、事件矩阵、开发清单与分项参考。静态演示补齐统一 pending 守卫、仅溢出文本全文访问及焦点归还；真实请求准入、领域上下文、异步选项/表单和批量结果仍是待消费者实现的契约。
- 设计页提供体验、接入、规则的页内导航，以及可发布的最小表格、远程列表、机构与批量组合示例。示例说明目标 API 与领域适配输入，不伪造已发布包或可安装导入路径。复制失败时仍可手动选择代码，不把剪贴板权限作为阅读门槛。
- 复杂场景用统一的本地模拟请求所有者连接查询、结果归属、状态和选择；状态预设、混合行动作与布局测量用于检查规则，不成为生产请求框架或第二套表格内核。说明、预览可演示项和消费者真实验收分开标注。
