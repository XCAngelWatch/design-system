## 视觉规则

- 表格文字、普通数字、时间及操作左对齐；金额列由业务列定义明确右对齐。数字仍使用 `tabular-nums`。水平单元格 padding 为 16px；固定操作列位于右侧不意味着内容右对齐。选择列与展开控制保留其原生专用布局。
- 按钮文案保持单行，按钮不被 flex 压缩；容器不足时由父级换行或既有更多菜单收纳，不截断动作名称。单选 Select 的已选长文本省略，Switch 滑块保持垂直居中。
- 文档站共用 SVG 示例使用 24×24 源画布、1.5 描边与 `currentColor`。消费者继续采用实际存在的 `@ant-design/icons` 导出或已审核局部 SVG；文档目录不等于已发布的图标包，不批量替换消费者图标。
- 静态状态矩阵关闭装饰动画；普通树节点隐藏重复装饰图标。保留展开开关、勾选、权限锁、加载进度等承担语义或操作的指示。

## 消费者同步范围

`contracts/tms-web-ui.json` 的 `visualPresentation` 记录上述规则，消费者原样镜像至 `docs/design-system/source-contract.json`，再同步文档和源码。消费者 Table token 的默认、middle 和 small 尺寸均使用 16px 水平间距；Select、Switch 和普通机构树节点已满足相应表现，不增加私有 DOM 覆盖。

## 2026-10-08 复核补迁与统一优化

首次迁移未完整覆盖表格列定义及英文，也未发现后加载的响应式 CSS 覆盖图标两列网格、按钮不收缩规则。已补齐 7 类列定义（普通数值、时间和操作左对齐，金额右对齐），使用新翻译 key 保留原跳页与选择列无障碍文案；删除图标目录的跨文件重复网格声明，统一蓝图工具栏和表单按钮不收缩。

同时修正本轮实际检查发现的同类问题：

- 图标分类提供 token 驱动的选中、悬停和键盘焦点样式；18 个静态 SVG 示例的描边与 1.5px 规范一致。
- 图标辅助操作收入更多菜单时补当前语言的可见文字；恢复宽屏时还原图标按钮，保留原控件和处理器。新增无依赖的行操作行为测试并接入部署前检查。
- 普通示例表按当前语言测量整个操作组，扩展操作列及表格最小宽度，保留其余列宽、固定布局和局部横向滚动。重算前恢复原始尺寸，避免连续缩放累计扩宽；菜单示例继续使用自身收纳逻辑。
- 英文表格不重复嵌套已有滚动容器，也不再用通用 720px 最小宽度覆盖冻结表的 1200px；冻结示例前两列各 160px，与第二列定位偏移一致。
- 中英文窄屏表单使用一致的单列布局，长 Select 文案省略；320px 文档工具栏允许切换器组换行。

本轮验证结果：

- 7 项源仓检查通过：i18n 覆盖、runtime、shell contract、行操作 runtime、consistency、consumer contract、evidence；页面注册 66/66、路由一致、JS 语法、shell 结构及差异格式检查通过。
- 使用 `file://` 完成 66 页 × 4 组渲染检查：1440px 中文 Light / 英文 Light、390px 中文 Dark / 英文 Dark。无页面级横向溢出、缺失 SVG、按钮文本越界、按钮收缩规则冲突或页面运行错误。
- 11 个路由中的 12 张操作表，按中英文分别经过 390 → 768 → 1440 → 390 → 600 → 390px 共 132 次路由/屏宽检查；整组按钮未越出操作单元格，回到原宽度后表宽一致。中英往返尺寸稳定；冻结表保持 1200px，首列及第二列偏移均为 160px，右侧操作列在横滚后仍贴合容器。
